# Sweet Sugar - Frontend

Frontend del sistema de gestión Sweet Sugar, desarrollado con React JS y Vite.

## Funcionalidades

- Gestión de clientes.
- Registro de clientes.
- Edición de clientes.
- Eliminación de clientes.
- Consumo de servicios REST mediante Axios.

## Tecnologías utilizadas

- React JS
- JavaScript
- Axios
- React Router
- CSS
- Vite

## Ejecución del proyecto

1. Instalar dependencias:

   `npm install`

2. Iniciar el servidor de desarrollo:

   `npm run dev`
